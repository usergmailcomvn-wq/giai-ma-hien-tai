# Giải mã hiện tại – Trò chơi tương tác

Website tĩnh được xuất bản bằng GitHub Pages. `index.html` tải các phần nội dung trò chơi trong `payload/` và dựng trang hoàn chỉnh.

## Xuất bản
Trong **Settings → Pages**, chọn **Deploy from a branch**, chọn `main` và `/(root)`, sau đó Save. GitHub Pages sẽ phục vụ trang tại `https://usergmailcomvn-wq.github.io/giai-ma-hien-tai/`.

Kho lưu trữ này công khai; không thêm thông tin riêng tư hoặc bí mật.
